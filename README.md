# Ho'oponopono

Prática guiada pela voz. A tela mostra as quatro frases. O aplicativo escuta você falando e conta os blocos. O sinal soa a cada dez blocos.

1. Sinto muito
2. Me perdoe
3. Obrigada
4. Eu te amo

Abra no Chrome, toque em **Escutar** e permita o microfone. O reconhecimento de voz do navegador precisa de internet.

## Publicar no GitHub Pages

O site é um arquivo estático. No repositório, em **Settings → Pages**:

1. Em **Build and deployment**, escolha **Deploy from a branch**.
2. Branch **main**, pasta **/ (root)**.
3. Salve.

O endereço fica `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.
